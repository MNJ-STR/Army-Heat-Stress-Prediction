🌡️ Army Soldier Heat Stress Risk Prediction

📌 Project Overview

This project uses Machine Learning to classify the potential heat stress risk level of soldiers based on environmental and physical parameters.

The system predicts three risk categories:

- LOW
- MODERATE
- HIGH

🎯 Problem Statement

Soldiers performing physical activities in hot and humid environments may face heat-related health risks. This educational project demonstrates how Machine Learning can classify heat stress risk using input parameters.

⚙️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest
- Streamlit

📊 Input Features

- Temperature
- Humidity
- Heart Rate
- Body Temperature
- Activity Level
- Exercise Duration
- Hydration Level

🤖 Machine Learning Algorithm

Random Forest Classifier

📁 Project Files

- "app (1).py" – Streamlit application
- "army_heat_stress_model.pkl" – Trained ML model
- "feature_columns.pkl" – Model input features
- "requirements (1).txt" – Required Python libraries

🚀 How to Run

Install dependencies:

pip install -r "requirements (1).txt"

Run the application:

streamlit run "app (1).py"

⚠️ Disclaimer

This project uses synthetic data and illustrative risk-scoring rules for educational purposes only. It is not medically validated and must not be used for actual military safety decisions, diagnosis, or treatment.
